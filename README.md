# Makemore words

A copy of the [original Karpathy repository](https://github.com/karpathy/makemore) done by hand by myself while following Andrej's video. 

## Objective

This repository objective is to do the basic NLP processing practices so I can practice with a dummy example. 
In this case, the file on the ./data/ folder is a list of the most common names for 2018 in the US. 

We'll try to build a Language Model that allows us to "Make More Words" using several techniques.
